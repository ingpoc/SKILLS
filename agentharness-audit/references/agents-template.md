### P01 — Cache-Stable System Prompt — Current: X.X/10 → Target: 9.5/10

**What you have**:
`<file>:<line>` — <one sentence describing what exists>

**What's missing**:
<concrete gap — e.g., "Timestamp includes minute-precision, invalidating prefix cache every turn">

**Architecture to adopt**:
1. Change `<file>:<line>` — replace minute-precision timestamp with date-only:
   ```python
   # Change this:
   timestamp = datetime.now().strftime('%Y-%m-%d %H:%M:%S')
   # To this:
   timestamp = datetime.now().strftime('%A, %B %d, %Y')  # date-only for cache stability
   ```
2. Cache the assembled system prompt on agent init:
   ```python
   self._cached_system_prompt = None  # built once, invalidated only after compression
   ```
3. Rebuild only after compression events — call `invalidate_system_prompt()` in your
   compaction handler, not in the per-turn loop.

**Canonical Architecture Pattern** (from `references/architecture.md`):
- **Pattern**: Three-tier prompt — immutable identity/tools (tier 1), stable behavioral
  guidance (tier 2), volatile session state (tier 3). Only tier 3 changes per turn.
  Date-only timestamp in tier 1; prompt cached on init and rebuilt only after compaction.
- **Anti-pattern**: Timestamp with minute or second precision, or rebuilding the prompt
  from scratch every turn — busts prefix cache, wastes tokens on every API call.
- **Rationale**: Anthropic's prompt cache TTL is 5 minutes. A stable prefix that matches
  token-for-token across turns gets cache hits, reducing TTFT and per-token cost.
- **Winner**: Hermes `agent/system_prompt.py:269-271` + `conversation_loop.py` rebuild guard.

**Reference**: Hermes `agent/system_prompt.py:269-271` — date-only timestamp with explicit
cache invariant comment. `agent/conversation_loop.py` rebuilds only after compression.

**Acceptance criteria**:
- [ ] System prompt is byte-identical across all turns in a session
- [ ] Timestamp changes at most once per day
- [ ] Compression event is the only trigger for prompt rebuild
- [ ] Code comment documents the cache invariant
